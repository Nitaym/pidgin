Pidgin Spec

Product Split:

1. Direct Conversation

Every agent should be reachable like a person:
text them, call them, email them, or summon them from Pidgin.

2. Meeting Participation

Agents are invited to meetings like coworkers.

Both modes are needed for the MVP. However, to simplify, we'll focus on only one option for each.

  1. Web Voice Button for immediate conversation
  2. Recall.ai or equivalent for meeting joining

Reference

Part of what makes an agent useful is that you could talk to it. This is a must for the MVP phase

Our options are these: | Option | Simplicity | Good for | Notes | | ---------------------------- | ------------: | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | | Phone call | Easiest | Real voice conversation | Twilio has bidirectional media streams: your server receives call audio and sends generated audio back into the call. Good fit for AI voice agents. (Twilio) | | Web voice button | Very easy | “Talk to Jane” inside your app | Browser mic → STT → agent → TTS. No telecom, no Zoom, no install. | | Slack text / audio clips | Easy | Workplace agent UX | Slack is great for text, but live Huddles are not cleanly programmable as a voice-agent surface; Slack Huddles are designed for human real-time coworking. (Slack) | | WhatsApp voice | Medium | Consumer-like UX | WhatsApp Business Calling API exists, but platform policy and availability are moving targets.
