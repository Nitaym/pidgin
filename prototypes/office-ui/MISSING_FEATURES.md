# Missing Features

## Visual
- Improve visual asthetics to match "standard" of computer games in the same field (inspiration: Stardew valley)

## Agents & chat
- Real LLM integration — replies are currently canned strings per role.
- Persistent chat history — conversations are session-only (not saved to backend).
- Real agent task execution / tool use.

## Collaboration & sync
- Multi-user support and authentication.
- Live status updates via WebSocket/SSE (status is local-only right now).
- Optimistic concurrency — last write wins on the office store.

## Office building
- Add / rename / resize rooms from the UI (rooms are hard-coded scenery).
- Snap decorations to a grid or to rooms.
- Export / import the office as a downloadable file.

## Robots
- More parts: hats, treads/wheels, faceplates, body shapes.
- Per-agent idle animations and reactions.

## Polish & quality
- Responsive / mobile layout.
- Undo / redo.
- Sound effects and ambient music.
- Automated tests (frontend + backend).
- Search / filter agents on large floors.
